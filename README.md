# sysadmin-noc-toolkit
Collection of practical Linux Bash scripts, network troubleshooting logs, and system monitoring setups for entry-level infrastructure roles

## Repository Structure
* `scripts/` - Bash scripts for system monitoring and network diagnostics.
* `docs/` - Guides and logs for network troubleshooting.

## Getting Started

### 1. Clone the repository
```bash
git clone [https://github.com/fazmilatif/sysadmin-noc-toolkit.git](https://github.com/fazmilatif/sysadmin-noc-toolkit.git)
cd sysadmin-noc-toolkit/scripts


### 2. Grant execute Permissions
bash
chmod +x *.sh


### 3. Run the scripts
bash
./system_health_check.sh
./ping_monitor.sh
